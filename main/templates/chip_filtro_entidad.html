{% comment %} Chip de filtro por entidad (chip -> modal selector_entidad). Reemplaza al buscador de texto libre por una eleccion acotada: el usuario ELIGE de una lista en vez de tipear, evitando errores y confusiones entre nombres parecidos. El estado APLICADO (id + nombre) vive en los data-* del contenedor; filtros_entidad.js lo lee para armar la URL de la busqueda AJAX y para reconstruir la etiqueta al elegir o limpiar. El chip vive fuera de la region que reemplaza el AJAX, asi que su estado sobrevive a los refrescos. Parametros de contexto: chip_id -> id unico del contenedor param -> nombre del parametro GET que aplica el filtro (empleado/vehiculo/destino) modal_id -> id del modal selector_entidad que abre icono -> simbolo Material etiqueta -> texto del chip cuando no hay filtro (por ej. "Empleado") valor_id -> estado aplicado que viene del server (id elegido) valor_nombre -> nombre a mostrar del estado aplicado {% endcomment %}
