{% comment %} Selector de entidad (modal reutilizable, chip -> modal). Reemplaza a los buscadores de texto libre por una lista acotada donde el usuario ELIGE en vez de tipear: evita errores de tipeo y confusiones entre nombres parecidos a la hora de filtrar o de tomar una decision. El JS (selector_entidad.js) es agnostico de la vista: abre/cierra el modal, filtra la lista por texto, navega con teclado y, al elegir, dispara el evento 'selector-entidad:elegir' sobre el contenedor con detail { id, principal }. Cada vista engancha ese evento a su propia logica (filtro AJAX, navegacion, etc.). Parametros de contexto: selector_id -> id unico del contenedor (para varias instancias en una pagina) titulo / descripcion / placeholder icono -> simbolo Material del encabezado (por defecto person_search) items -> ver selector_entidad_items.html sin_items -> mensaje cuando no hay items {% endcomment %}
